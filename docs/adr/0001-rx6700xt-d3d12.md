# ADR 0001 — Base D3D12 para RX 6700 XT

- Status: aceito.
- Data: 2026-11-26 UTC.

## Contexto

O objetivo é avançar o porto 1.0.2.1 na RX 6700 XT sem reimplementar o runtime.
Os candidatos Vulkan e D3D12 públicos têm níveis de maturidade diferentes.

## Decisão

Usar `avatarmanz/VIctory-7900XTX` e seu backend D3D12 como base.
O merge operacional parte de `c9c932c`; o README mais recente examinado é `2de9980`.
O fork é `hashtegui/VIctory-7900XTX`, branch `rx6700xt-adaptation`.

## Motivos

- É a base pública que já apresenta menus, world, save e gameplay controlável.
- Contém renderer ports, submit assíncrono, tradução de shaders e instrumentação.
- Portar o backend D3D12 exige menos trabalho na RX 6700 XT do que concluir o estágio 2/3 de Palmetto.
- A cópia em processo do Kelvaroq é um patch isolado e aplicável sem criar um runtime novo.

## Portas e riscos

- Port 6/7 do AvatarManz: mantidos como opção `-PortTune`; medidos no 7900 XTX, não na 6700 XT.
- Process-copy do Kelvaroq: medido em RTX 4070; os testes locais de página/alias passam, mas o ganho de frame na RDNA2 ainda precisa de A/B oficial.
- Series S: recomendado pelo README do AvatarManz; ganho preliminar local de 9-11 FPS contra 6-10 no Series X.
- Native 1280x720: rejeitado; FSR4 fixa `maxUpscaleSize=1920x1080`.
- RT: permanece desligado; RDNA2 deve ser mais lento que as placas NVIDIA citadas.

## Consequências

- O render interno deve ficar em 720p com upscale para 1080p.
- Toda afirmação de ganho exige dois braços, mesmo save, mesmo SHA e 300 s.
- O harness deve registrar TDR/device loss e reiniciar sem perder traces.
- Resultados anteriores ao harness são marcados como preliminares.
